# 是否是同一颗二叉树

[]: https://pintia.cn/problem-sets/15/exam/problems/type/7?problemSetProblemId=712	"7-4 是否同一棵二叉搜索树"

题目描述： 给定一个插入序列就可以唯一确定一棵二叉搜索树。然而，一棵给定的二叉搜索树却可以由多种不同的插入序列得到。例如分别按照序列{2, 1, 3}和{2, 3, 1}插入初始为空的二叉搜索树，都得到一样的结果。任务是对于输入的各种插入序列，判断它们是否能生成一样的二叉搜索树。

**输入格式：** 

输入包含若干组测试数据。
每组数据的第1行给出两个正整数 N (≤10) 和 L，分别是每个序列插入元素的个数和需要检查的序列个数。
第2行给出N个以空格分隔的正整数，作为初始插入序列。
最后L行，每行给出N个插入的元素，属于L个需要检查的序列。
简单起见，我们保证每个插入序列都是1到N的一个排列。当读到N为0时，标志输入结束，这组数据不要处理。

**输出格式：** 对每一组需要检查的序列，如果其生成的二叉搜索树跟对应的初始序列生成的一样，输出"Yes"，否则输出"No"。

### 输入样例:

```in
4 2
3 1 4 2
3 4 1 2
3 2 4 1
2 1
2 1
1 2
0
```

### 输出样例:

```out
Yes
No
No
```

```cpp

        ∙根据第一行序列建树T
        ·依据树T分别判别后面的L个序列是否能与T形成同一搜索树并输出结果
    
    return 0;
}
```

**需要设计的函数：** 1. 读数据建搜索树T

         2. 判别序列是否与T构成一样的搜索树

![是否是同一颗二叉树demo1](.\pic\是否是同一颗二叉树demo1.png)

**问题：** 如何判别序列3 2 4 1是否与树T一致?
**方法：** 在树T中按顺序搜索序列3 2 4 1中的每个数，如果每次搜索所经过的结点在前面均出现过，则一致；否则如果某次搜索中遇到前面未出现的结点，则不一致。

具体：

1. 判断输入的第一个树和很节点是否相等，相等则可以继续，并且将根节点的flag置1
2. 接着判断下一个输入，与根节点比较后进入左节点或右节点进行比较，这里分两种情况，节点的数字已经遍历过，flag=1，没有遍历过，flag=0
3. flag=1，代表已经出现过，输入数字和节点值进行比较后进入下一个节点，但是如果相等，代表输入出现重复，直接判定不相等。
4. flag=0，节点数字没有遍历过，如果节点数字和输入数字相等，则flag置1，表示已经遍历到，返回1退出，准备对下一个输入数字进行判断，如果不相等，说明按输入数字的顺序构建的树和原来的树不相等，直接返回0退出，表示树不相等。

代码如下：

```cpp
//如何判别（已经访问过的结点要进行标记，使flag=1）
//在树T中按顺序搜索序列中的每个数，如果每次搜索所经过的结点在前面均出现过，则一致；
//                              否则如果某次搜索中遇到前面未出现的结点，则不一致。
int check(BinTreeNode* T, int val){
    if(T->flag){
        if(val > T->data) return check(T->right, val);
        else if(val < T->data) return check(T->left, val);
        else return 0;  //如果V == T->v，意味着这个序列中有两个元素出现了两次以上，即重复出现，认为不一致
    }
    else{
        if(val == T->data){
            T->flag = 1;    //如果未被访问过的结点刚好是所搜索的，使flag=1
            return 1;
        } 
        else return 0;  //否则未被访问过的结点不是所搜索的，即遇到前面未出现的结点，使flag=0
    }
}

int Judge(BinTreeNode* T, int N){
    int val, same = 1;  // same用于标记二叉树是否相等
    std::cin >> val;
    if(val != T->data) same = 0;    //序列第一个元素与T的根结点不一致，那就不是同一棵树
    else T->flag = 1;

    for (int i = 1; i < N; ++i){
        std::cin >> val;
        if( same && (!check(T, val)) ) same = 0;
    }

    if(!same) return 0;
    else return 1;
}
```

check函数判断一个输入数字，Juge将其进行封装，对一整颗树的输入进行判断。

这里的same数字很重要，用于保证后面用于对比的树完全输出，而不是中间发现树不相等后就退出，导致剩余没输出的数字输入给下一个树。

```cpp
// 通过结构树组表示二叉树
struct BinTree{
    char element;
    int left, right;
}T1[MaxTree], T2[MaxTree];
```

这里会涉及一个问题，如何找到根节点，很简单，没有节点指向根节点，根据这个思想就可以找到根节点。

在创建树的时候，用一个数组对左右节点对应索引的位置进行标记，数据读完后，对这个数组进行遍历找到没被标记的索引，这个索引对应的节点就是根节点。

同时要注意输入的左右节点中含有 '-' 表示空节点，所以在接收左右节点时，先用char接收，如果不是 '-' ，再通过减 '0' ，返回真正的int值。

```cpp
// 返回值为树根
int BuildTree(BinTree T[]){
    int n; std::cin >> n;   // 节点个数
    int check[MaxTree];     // 用来寻找根节点的数组
    char left, right;       // 输入中有"-"，先用char接收输入，后续转数字
    int root = -1;
    if(n){
        for (int i = 0; i < n; ++i) check[i] = 0;
        for (int i = 0; i < n; ++i){
            std::cin >> T[i].element >> left >> right;
            // 判断左右子树是否为空节点，同时标记出现过的子树，没出现过的就是根节点
            if(left != '-'){
                T[i].left = left - '0';
                check[T[i].left] = 1;   // 出现过，标记为1
            }
            else if(left == '-') T[i].left = -1;

            if(right != '-'){
                T[i].right = right - '0';
                check[T[i].right] = 1;   // 出现过，标记为1
            }
            else if(right == '-') T[i].right = -1;

            // 寻找根节点，出现过的节点都会被标记1，没出过的就是0，即为根节点
            // 根节点不会被指向
            for (int i = 0; i < n; ++i){
                if (!check[i]){
                    root = i;
                    break;
                }
            }
        }
    }
    return root;
}
```

接下来判断是否同构，涉及一下情况：

1. 都是空树，则必然同构
2. 其中一个是空树，必然步同构
3. 根节点不同，必然不同构
4. 同时左子树或同时右子树全为空，则通过递归进行判断。一开始没搞懂为什么代码里为什么只有左子树全空的部分，为什么没有右子树全空，原因是这个情况是对称的有一个就足够了，假设真的出现右子树为空的情况，第一中情况已经覆盖，没必要再多写情况了。
5. 左子树不为空且左子树的值相等（同样对称情况，一个足够）
6. 左右子树都不为空但是值不相等，需要交换进行判断
